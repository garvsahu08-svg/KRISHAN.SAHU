# KRISHAN WEBDESIGNER portfolio
Static site (HTML/CSS/JS) — no build step.

## Edit
Sab kuch `config.js` mein: WhatsApp, email, socials, skills, projects. Khali ("") link = dikhega nahi.

## Portrait
Transparent cutout `assets/krishan-cutout.webp` naam se save karo (~640x800, <150 KB). Remove.bg / Photoroom / Canva Background Remover se background hatao, phir WebP mein export karo. Jab tak file nahi hai, "K" monogram dikhta hai.

## Render par deploy
GitHub par push karo -> Render > New > Static Site -> repo chuno. Build Command khali, Publish Directory `.`
(ya `render.yaml` se Blueprint deploy karo).
